this is a php script that takes requests to your server with Host headers www.boomlings.com and www.robtopgames.org, and modifies them to work with the geometry dash servers in the modern day. it currently supports 2.0 and 2.1. THIS IS NOT A PRIVATE SERVER, THIS COMMUNICATES WITH THE OFFICIAL GD SERVER.
there are some bugs with 2.0, such as level comments not appearing. i don't know why, but i will look into a fix.
what this fixes in 2.1: login, save, load, scores, daily, weekly. you can now also play levels uploaded from 2.2. however, this could crash your game. the proxy modifies the descriptions of levels to include the origin gd version at the end. this is the version of gd the level was uploaded from, so you can determine if it's safe to play.
what this fixes in 2.0: login, save, load, scores, daily, weekly, comment uploads, user profile, level downloads. it also allows you to play levels from 2.1 or 2.2. once again, could crash your game, but you can check the origin gd version in the level description.
extra things: search `gdspdailyhistory` (case insensitive) to access the history of daily levels. search `gdspweeklyhistory` (case insensitive) to access the history of weekly levels. search `gdspeventhistory` (case insensitive) to access the history of event levels. search `gdspsent` (case insensitive) to access moderator sent levels.
1.9 support has been added! 1.9: login, save/load. loading a modern save file from 2.1 or 2.2 (maybe even 2.0?) will cause 1.9 to crash. unfortunately, 1.9 is from the era where unregistered accounts were the norm, and registered accounts were only for saving and loading game progress. as a result, 1.9 doesn't attach any account credentials to its http requests.
if you are wondering what "gdsp" means, it is the original name of this project, "GDSecondaryProxy", which was in the form of a python 3 script.
claude sonnet 4.6 was used to make skeleton code and to fix difficult bugs. i am somewhat new to php, but have had some experience in the past. most of the code is human written or inspired by other GDPS implementations.
thanks to https://boomlings.dev for providing documentation for the server endpoints and parameters. charles proxy and proxifier were used to capture http traffic from 2.113.
